# Contributing to Libre Skill Tree 

Thank you for your interest in helping build the "Skill Tree of Life"! We love pull requests.

## Tech Stack
- **State Management:** Flutter BLoC
- **Database:** Isar (Local)  
- **Graphics:** GraphX

## How to Contribute
1. **Report Bugs:** Open an issue describing the bug and how to reproduce it.
2. **Suggest Features:** We are open to new "branches" in the skill tree!
3. **Submit Code:**
    - Fork the repo.
    - Create a branch: `git checkout -b feature/your-feature-name`.
    - Ensure your code follows `flutter_lints`.
    - Test the app properly before submitting any code.
    - Open a Pull Request.

## Code Style
- Run `dart run build_runner build` if you modify Isar models.
